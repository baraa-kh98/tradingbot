### [1] XAUUSD Regime Filter — استدعاءات API حية بدون Cache
- **الملف:** `strategy/xauusd_signal.py` السطر 126–162
- **المشكلة:** دالة `_regime_check()` تستدعي `yfinance` في **كل دورة** (كل 15 دقيقة)
  - طلب HTTP لـ VIX: `yf.Ticker("^VIX").history(period="1d")`
  - طلب HTTP لـ TNX: `yf.Ticker("^TNX").history(period="1d")`
  - إذا كانت الشبكة بطيئة → الدورة تتأخر 5-30 ثانية
  - إذا فشلت API → **fail-open** → كل الصفقات مسموحة بدون Regime Filter
- **الخطر الفعلي:** خلال جلسة NY (13:00-16:00 UTC = 12 دورة):
  - 24 طلب HTTP لكل جلسة
  - أي انقطاع شبكة → Regime Filter معطّل تلقائياً
- **الإصلاح المقترح:**
  ```python
  # في XAUUSDSignalGenerator.__init__():
  self._regime_cache = None      # (bool, timestamp)
  self._regime_cache_ttl = 3600  # ساعة واحدة بالثواني
  
  def _regime_check(self) -> bool:
      import time
      now = time.time()
      if self._regime_cache and (now - self._regime_cache[1]) < self._regime_cache_ttl:
          return self._regime_cache[0]  # استخدم الكاش
      result = self._fetch_regime()      # استدعاء API فعلي
      self._regime_cache = (result, now)
      return result
  ```
- **الحالة:** ⏳ ينتظر موافقتك (ملف استراتيجية)
- **الأولوية:** متوسطة — لا تؤثر على المنطق، تؤثر على الاستقرار
