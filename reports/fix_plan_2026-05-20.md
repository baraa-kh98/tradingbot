- **المشكلة:** `_regime_check()` تستدعي yfinance API في كل دورة (كل 15 دقيقة) بدون Cache
  - 24 طلب HTTP في جلسة NY واحدة (13-16 UTC)
  - عند فشل API → fail-open → جميع صفقات XAUUSD مسموحة بدون فلتر
- **الإصلاح المقترح:**
  ```python
  def __init__(self, ...):
      ...
      self._regime_cache = None  # (result: bool, timestamp: float)

  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result
  ```

  ```python

  ```
  هذا يضع SL فوق entry بـ 2 pips. عند ضرب SL:
  - الموضع الحالي (entry + offset): نشتري بسعر أعلى من البيع → **خسارة 2 pip**
