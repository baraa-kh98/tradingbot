### [A] 🚨 [**31 يوم** ← رقم قياسي مطلق جديد] Cache لـ `_regime_check()` — xauusd_signal.py:129

- **الملف:** `strategy/xauusd_signal.py:129-164`
- **المشكلة:** `_regime_check()` تستدعي yfinance API في كل دورة (كل 15 دقيقة) بدون Cache
  - 96 طلب HTTP يومياً بدون داعٍ (4 استدعاءات/ساعة × 24)
  - عند فشل API → `fail-open` (كل صفقات الذهب مسموحة بدون فلتر ماكرو)
  - Dead Import `timedelta` داخل الدالة على L136 يُحذف تلقائياً مع هذا الإصلاح
- **الإصلاح المقترح:**
  ```python
  _regime_cache: dict = {}
  REGIME_TTL = 3600  # ساعة كاملة

  def _regime_check(self) -> bool:
      import time
      now = time.time()
      if self._regime_cache and (now - self._regime_cache["ts"]) < self.REGIME_TTL:
          return self._regime_cache["result"]
      result = self._fetch_regime_live()
      self._regime_cache = {"result": result, "ts": now}
      return result
  ```
- **التأثير:** 96 طلب/يوم → 24 طلب/يوم (توفير 75%)
- **الحالة:** ⏳ **ينتظر موافقتك** (31 يوم ← رقم قياسي مطلق جديد)
