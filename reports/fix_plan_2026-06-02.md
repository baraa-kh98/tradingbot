### [A] 🚨 [**17 يوم** ← رقم قياسي مطلق] Cache لـ `_regime_check()` — xauusd_signal.py:129

- **الملف:** `strategy/xauusd_signal.py` السطور 129–164
- **المشكلة المركّبة:**
  1. كل دورة 15 دقيقة في جلسة NY (13–16 UTC): **طلبان HTTP إلى yfinance** لجلب VIX + TNX
  2. النتيجة: **12–48 طلب يومياً بلا داعٍ** — VIX لا يتغير خلال الساعة
  3. **عند فشل yfinance/الشبكة:** `fail-open = True` → XAUUSD يتداول حتى في بيئة ماكرو سيئة
  4. **Dead code:** `from datetime import datetime, timedelta` (السطر 136) داخل الدالة — لا يُستخدم أبداً
- **الإصلاح المقترح (2 دالة بدل 1):**
  ```python
  # في __init__ — سطر واحد:
  self._regime_cache = None  # (result: bool, timestamp: float)

  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result

  def _fetch_regime_live(self) -> bool:
      try:
          import yfinance as yf
          vix = yf.Ticker("^VIX")
          vix_data = vix.history(period="1d")
          if not vix_data.empty:
              current_vix = float(vix_data["Close"].iloc[-1])
              if current_vix > self.VIX_MIN:
                  return True
          try:
              tnx = yf.Ticker("^TNX")
              tnx_data = tnx.history(period="1d")
              if not tnx_data.empty:
                  nominal_yield = float(tnx_data["Close"].iloc[-1])
                  estimated_cpi = 2.8
                  real_yield = nominal_yield - estimated_cpi
                  if real_yield < self.REAL_YIELD_MAX:
                      return True
          except Exception:
              pass
          return False
      except Exception as e:
          _log.warning(f"_regime_check error (fail-open): {e}")
          return True
  ```
- **الفائدة المباشرة:** 48 طلب → 3 فقط يومياً | يُحل Dead Import تلقائياً
- **الحالة:** ⏳ ينتظر موافقتك (**17 يوم** — أطول انتظار في كل السجل)
- **التوصية:** طبّقه **هذا الأسبوع** — آمن تماماً، لا يغيّر منطق الاستراتيجية
