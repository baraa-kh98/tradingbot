- **الملف:** `strategy/xauusd_signal.py:129-164`
- **المشكلة المؤكدة:**
  - `yf.Ticker("^VIX").history(period="1d")` + `yf.Ticker("^TNX")` — HTTP calls في **كل دورة 15 دقيقة**
  - = **96 طلب HTTP يومياً** بدون داعٍ (3,000+ طلب شهرياً)
  - عند فشل الشبكة → `return True` (fail-open) → تداول بدون فلتر ماكرو
  - `from datetime import datetime, timedelta` في السطر 136 — Dead Code لا يُستخدم أبداً

- **الإصلاح المقترح (20 دقيقة):**
  ```python
  # في __init__ بعد السطر 62 (إضافة):
  self._regime_cache = None  # (result: bool, timestamp: float)

  # استبدال _regime_check كاملاً (السطور 129-164):
  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result

  def _fetch_regime_live(self) -> bool:
      try:
          import yfinance as yf
          vix = yf.Ticker("^VIX")
          vix_data = vix.history(period="1d")
          if not vix_data.empty:
              current_vix = float(vix_data["Close"].iloc[-1])
              if current_vix > self.VIX_MIN:
                  return True
          try:
              tnx = yf.Ticker("^TNX")
              tnx_data = tnx.history(period="1d")
              if not tnx_data.empty:
                  nominal_yield = float(tnx_data["Close"].iloc[-1])
                  estimated_cpi = 2.8
                  real_yield = nominal_yield - estimated_cpi
                  if real_yield < self.REAL_YIELD_MAX:
                      return True
          except Exception:
              pass
          return False
      except Exception as e:
          _log.warning(f"_regime_check error (fail-open): {e}")
          return True
  ```
- **الفائدة:** 96 طلب → 1 طلب/ساعة = توفير 95% API calls
- **الوقت:** 20 دقيقة
- **الحالة:** ⏳ **26 يوم ← رقم قياسي مطلق — ينتظر موافقتك**
