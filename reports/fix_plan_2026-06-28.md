- **الإصلاح:**
  ```python
  # الحالي — طلبان HTTP أولاً ثم الفحص:
  if not self._regime_check():   # HTTP call
      return None
  if self._in_trade:             # free check (يأتي متأخراً)
      return None

  # الصحيح — الفحص المجاني أولاً:

      return None
  if not self._regime_check():   # HTTP فقط عند الحاجة الفعلية
      return None
  ```
