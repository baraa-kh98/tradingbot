### [A] 🚨🚨 [**15 يوم** ← رقم قياسي — CRITICAL] xauusd_signal.py — Cache لـ `_regime_check()`
- **الملف:** `strategy/xauusd_signal.py:129-164`
- **المشكلة:**
  - `_regime_check()` تُطلق طلبَي HTTP (VIX + TNX من yfinance) في كل دورة 15 دقيقة
  - 4-16 طلب/ساعة × 3 ساعات NY = 12-48 طلب يومياً بدون داعٍ (VIX لا يتغير كثيراً خلال الساعة)
  - عند فشل API أو بطء الشبكة: fail-open → XAUUSD يتداول حتى في بيئة ماكرو سيئة
  - `from datetime import datetime, timedelta` داخلها (سطر 136) — dead import يُحذف معها

- **الإصلاح المقترح (نظيف ومضمون):**
  ```python
  # في __init__:
  self._regime_cache = None  # (result: bool, timestamp: float)

  # استبدال _regime_check كاملاً:
  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result

  def _fetch_regime_live(self) -> bool:
      try:
          import yfinance as yf
          vix = yf.Ticker("^VIX")
          vix_data = vix.history(period="1d")
          if not vix_data.empty:
              current_vix = float(vix_data["Close"].iloc[-1])
              if current_vix > self.VIX_MIN:
                  return True
          try:
              tnx = yf.Ticker("^TNX")
              tnx_data = tnx.history(period="1d")
              if not tnx_data.empty:
                  nominal_yield = float(tnx_data["Close"].iloc[-1])
                  estimated_cpi = 2.8
                  real_yield = nominal_yield - estimated_cpi
                  if real_yield < self.REAL_YIELD_MAX:
                      return True
          except Exception:
              pass
          return False
      except Exception as e:
          _log.warning(f"_regime_check error (fail-open): {e}")
          return True
  ```
- **الفائدة:** 48 طلب → 3 فقط يومياً | حماية من انقطاع الشبكة | يُحل Dead Import أيضاً
- **الوقت المقدّر:** 20 دقيقة
- **الحالة:** ⏳ **ينتظر موافقتك — الأحد آخر فرصة قبل فتح الأسواق**
