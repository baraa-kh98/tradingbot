### [A] 🚨 [**19 يوم** ← رقم قياسي مطلق] Cache لـ `_regime_check()` — xauusd_signal.py

- **الملف:** `strategy/xauusd_signal.py:129-164` (دالة `_regime_check` + `__init__`)
- **المشكلة الفعلية:**
  - كل 15 دقيقة في جلسة NY: **طلبان HTTP** لـ yfinance (VIX + TNX)
  - يومياً: 12–48 طلب غير ضروري — VIX لا يتغير خلال الساعة
  - عند فشل الشبكة: **fail-open** → XAUUSD يتداول حتى في بيئة ماكرو سيئة
  - Dead Code Import: `from datetime import datetime, timedelta` (السطر 136) → يُحذف تلقائياً مع الإصلاح

- **الإصلاح المقترح:**
  ```python
  # في __init__ — سطر واحد إضافي:
  self._regime_cache = None  # (result: bool, timestamp: float)

  # استبدال _regime_check:
  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result

  def _fetch_regime_live(self) -> bool:
      try:
          import yfinance as yf
          vix = yf.Ticker("^VIX")
          vix_data = vix.history(period="1d")
          if not vix_data.empty:
              current_vix = float(vix_data["Close"].iloc[-1])
              if current_vix > self.VIX_MIN:
                  return True
          try:
              tnx = yf.Ticker("^TNX")
              tnx_data = tnx.history(period="1d")
              if not tnx_data.empty:
                  nominal_yield = float(tnx_data["Close"].iloc[-1])
                  estimated_cpi = 2.8
                  real_yield = nominal_yield - estimated_cpi
                  if real_yield < self.REAL_YIELD_MAX:
                      return True
          except Exception:
              pass
          return False
      except Exception as e:
          _log.warning(f"_regime_check error (fail-open): {e}")
          return True
  ```
- **الفائدة:** 48 طلب → 3 طلبات يومياً | حماية fail-open | يُحل Dead Import تلقائياً
- **الوقت المقدّر:** 20 دقيقة
- **الحالة:** ⏳ ينتظر موافقتك **(19 يوم ← رقم قياسي مطلق — اليوم آخر فرصة قبل NFP)**
