### [A] ⚡⚡⚡ Cache لـ `_regime_check()` — 35 يوم انتظار ← رقم قياسي مطلق
- **الملف:** `strategy/xauusd_signal.py:129`
- **المشكلة الفعلية:**
  - `_regime_check()` تستدعي `yf.Ticker("^VIX").history()` + `yf.Ticker("^TNX").history()` في **كل دورة (كل 15 دقيقة)**
  - = **96 طلب HTTP يومياً** بدون أي فائدة (VIX لا يتغير كل 15 دقيقة)
  - عند فشل أي طلب → `except Exception → return True` أي **fail-open** (كل الصفقات تمر بدون فلتر)
  - Dead import داخل الدالة: `from datetime import datetime, timedelta` (L136) — لا يُستخدم أبداً
- **الإصلاح:**
  ```python
  # في __init__ أضف بعد self._tp = 0.0:
  self._regime_cache: Optional[bool] = None
  self._regime_cache_time: float = 0.0
  REGIME_CACHE_TTL: int = 3600  # ثانية = ساعة واحدة

  # في _regime_check() أول شيء قبل try:
  import time
  now = time.time()
  if self._regime_cache is not None and (now - self._regime_cache_time) < self.REGIME_CACHE_TTL:
      return self._regime_cache

  # في كل return True / return False قبل الـ return:
  self._regime_cache = result; self._regime_cache_time = time.time()

  # احذف السطر L136: from datetime import datetime, timedelta (dead import)
  ```
- **التأثير:** 96 طلب/يوم → 24 طلب/يوم | fail-safe أكثر موثوقية | يحذف dead import
- **الوقت المقدّر:** 10-15 دقيقة
- **الحالة:** ⏳ **ينتظر موافقتك — النافذة المثالية الآن (السبت)**
