  ```python

      tracked["breakeven_done"] = True
  ```
  لصفقات SELL الجديدة: `new_sl = entry - offset` ≠ `entry + offset` → `breakeven_done` لا يُعيَّن أبداً → شاشة الحالة تُظهر Break-Even = ❌ حتى بعد تطبيقه.
- **الإصلاح:** التحقق من كلا الاتجاهين:
  ```python
  # بعد الإصلاح:
  _be_off = self.rm.breakeven_offset_pips * PIP_VALUE
  if new_sl in (round(entry + _be_off, 3), round(entry - _be_off, 3)):
      tracked["breakeven_done"] = True
  ```
- **التأثير على التداول:** لا يوجد — المنطق الوظيفي لـ Break-Even سليم تماماً. هذا إصلاح للتتبع فقط (`get_status()` + Telegram notifications).
