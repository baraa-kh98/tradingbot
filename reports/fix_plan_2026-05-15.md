### [1] datetime.now() يستخدم Local Time بدل UTC في الـ Main Loop
- **الملف:** `main.py` الأسطر 619–620 ، 651 ، 663
- **المشكلة:** ثلاثة استخدامات لـ `datetime.now()` (local timezone) بدل `datetime.now(timezone.utc)` في الحلقة الرئيسية:
  1. **السطر 620:** `today = datetime.now().date()` — يُقرّر متى يبدأ يوم جديد (reset اليومي، تقرير الأسبوع)
  2. **السطر 651:** `datetime.now().hour == VISION_REPORT_HOUR` — يُطلق تقرير الرؤية الصباحية
  3. **السطر 663:** `_now_h = datetime.now().hour` — يُطلق الـ heartbeat و push_logs
  
  إذا كان VPS في timezone غير UTC (مثلاً +3)، الـ heartbeat يُرسَل على ساعات خاطئة (مثلاً 03:00، 07:00... بدل 00:00، 04:00...)، والـ daily reset يحدث في منتصف ليل VPS لا UTC، مما يُسبّب تعارضاً مع أسماء الملفات (التي تستخدم UTC بالفعل).
- **الكود القديم:**
  ```python
  # السطر 619-620
  from datetime import datetime
  today = datetime.now().date()
  # السطر 651
  if datetime.now().hour == VISION_REPORT_HOUR ...
  # السطر 663
  _now_h = datetime.now().hour
  ```
- **الكود الجديد:**
  ```python
  # السطر 619-620
  from datetime import datetime, timezone
  today = datetime.now(timezone.utc).date()
  # السطر 651
  if datetime.now(timezone.utc).hour == VISION_REPORT_HOUR ...
  # السطر 663
  _now_h = datetime.now(timezone.utc).hour
  ```
- **التحقق:** `grep -n "datetime.now()" main.py` → لا نتائج بدون `timezone.utc`
- **الحالة:** ✅ طُبّق تلقائياً
