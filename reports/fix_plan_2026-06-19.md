- **الإصلاح المقترح:**
  ```python

  # في _regime_check() أضف في البداية:
  import time
  if self._regime_cache is not None and (time.time() - self._regime_cache_time) < self.REGIME_CACHE_TTL:
      return self._regime_cache
  # ... باقي الكود ...
  # في نهاية كل return:
  self._regime_cache = result
  self._regime_cache_time = time.time()
  ```

- **التأثير:** 96 طلب → 24 طلب/يوم | fail-safe أفضل | يُحل dead import تلقائياً
