  - عند فشل API → `fail-open` (كل صفقات الذهب مسموحة بدون فلتر ماكرو)

- **الإصلاح المقترح:**
  ```python
  _regime_cache: dict = {}  # {"result": bool, "ts": float}
  REGIME_TTL = 3600  # Cache لمدة ساعة كاملة

  def _regime_check(self) -> bool:
      import time
      now = time.time()
      if self._regime_cache and (now - self._regime_cache["ts"]) < self.REGIME_TTL:
          return self._regime_cache["result"]
      result = self._fetch_regime_live()
      self._regime_cache = {"result": result, "ts": now}
      return result
  ```
- **التأثير:** 96 طلب/يوم → 24 طلب/يوم (توفير 75%)
