### [A] 🚨 [**21 يوم** ← رقم قياسي مطلق] Cache لـ `_regime_check()` — xauusd_signal.py

- **الملف:** `strategy/xauusd_signal.py:129-164`
- **المشكلة الفعلية (مؤكدة):**
  - السطر 135: `import yfinance as yf` — يُستدعى **في كل دورة** (كل 15 دقيقة)
  - السطر 139-140: `yf.Ticker("^VIX").history(period="1d")` — HTTP call بدون cache
  - السطر 149-151: `yf.Ticker("^TNX").history(period="1d")` — HTTP call ثانٍ
  - السطر 136: `from datetime import datetime, timedelta` — **Dead code لا يُستخدم أبداً**
  - عند فشل الشبكة → `return True` (fail-open) → يتداول بدون فلتر ماكرو

- **الإصلاح المقترح:**
  ```python
  # في __init__ (بعد السطر 62):
  self._regime_cache = None  # (result: bool, timestamp: float)

  # استبدال _regime_check (السطور 129-164) بالكامل:
  def _regime_check(self) -> bool:
      import time as _t
      now = _t.time()
      if self._regime_cache and (now - self._regime_cache[1]) < 3600:
          return self._regime_cache[0]
      result = self._fetch_regime_live()
      self._regime_cache = (result, now)
      return result

  def _fetch_regime_live(self) -> bool:
      try:
          import yfinance as yf
          vix = yf.Ticker("^VIX")
          vix_data = vix.history(period="1d")
          if not vix_data.empty:
              current_vix = float(vix_data["Close"].iloc[-1])
              if current_vix > self.VIX_MIN:
                  return True
          try:
              tnx = yf.Ticker("^TNX")
              tnx_data = tnx.history(period="1d")
              if not tnx_data.empty:
                  nominal_yield = float(tnx_data["Close"].iloc[-1])
                  estimated_cpi = 2.8
                  real_yield = nominal_yield - estimated_cpi
                  if real_yield < self.REAL_YIELD_MAX:
                      return True
          except Exception:
              pass
          return False
      except Exception as e:
          _log.warning(f"_regime_check error (fail-open): {e}")
          return True
  ```
- **الفائدة:** 96 طلب → 3 طلبات/يوم | يُحذف Dead Import تلقائياً
- **الوقت:** 20 دقيقة
- **الحالة:** ⏳ **21 يوم ← ينتظر موافقتك — اليوم السبت**
